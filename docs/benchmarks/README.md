# Community benchmark results

User-submitted InferBridge measurements. Each file is one result (or one machine's
set of results) using the template in
[Context and memory → Contributing benchmarks](../CONTEXT_AND_MEMORY.md#contributing-benchmarks).

Name files `<cpu-or-platform>-<model>-<device>-<context>.md`, for example
`core-ultra-7-155h-qwen2.5-7b-int4-gpu-32k.md`.

These are user reports. They are not certification evidence and do not change
a model's verified status; see [Known issues](../KNOWN_ISSUES.md) and the
[Compatibility matrix](../COMPATIBILITY_MATRIX.md) for how reports are treated.
