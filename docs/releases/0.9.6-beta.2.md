# InferBridge 0.9.6-beta.2

This beta hotfix hardens the Windows installer and first-launch path after the 0.9.6-beta.1 installer could leave users at a raw packaged-runtime crash immediately after Setup completed.

This is a **beta pre-release** and its artifacts are **unsigned**. Windows may report an unknown publisher and SmartScreen may warn. Verify downloads against the published SHA-256 checksums.

## Installer and first-launch fixes

- The PyInstaller bundle now explicitly includes setuptools package data needed by its `pkg_resources` bootstrap path. This prevents the historical failure mode where the frozen executable starts with Python modules present but crashes because vendored runtime data such as `jaraco.text` resources was omitted.
- The packaged executable now enters through a dedicated frozen-process boundary. Unexpected application-startup exceptions are contained and reported as a controlled InferBridge startup failure instead of escaping into PyInstaller's raw `Unhandled exception in script` window.
- A lightweight `--bootstrap-smoke` mode validates the frozen interpreter and PyInstaller runtime hooks without starting the tray, server, browser, or model stack.
- Setup runs that bootstrap probe from the **actual installed directory** after files are copied. It retries transient failures and only offers the normal post-install launch when the installed runtime passes.
- If the installed bootstrap is invalid, Setup leaves user models and settings untouched, suppresses the automatic launch, and reports a reinstall action instead of immediately launching a known-broken executable.

## Regression coverage

- Added source contracts that require the hardened frozen entry point, setuptools runtime data collection, bootstrap-smoke short circuit, top-level exception containment, and the installer post-copy probe.
- The existing mandatory release `verify-native` stage still runs the packaged OpenVINO and conversion-import smoke test before installer compilation.

## Compatibility

- Persistent data schema remains version 1.
- Existing models, settings, caches, history, onboarding state, and diagnostics remain compatible with 0.9.5 and 0.9.6-beta.1.
- Installer identity and install location are unchanged, so this build upgrades the existing InferBridge installation in place.

## Still requires physical Windows qualification

Source-level and packaged release gates cannot prove every host-specific condition. Before promoting this beta to stable, exercise a fresh install and an in-place upgrade on a real Windows machine and confirm tray launch, server readiness, browser opening, uninstall, and retained user data. Authenticode signing also remains unverified unless a signed release build completes the repository's signing gate.
