# InferBridge 1.1.0 — native Windows app

Minor feature release, promoted from 1.1.0-beta.1. InferBridge now opens as a native Windows (WinUI 3) app, and this is the first version prepared for Microsoft Store. The Python/OpenVINO engine, model files, data folders and API are unchanged from 1.0.x.

## Highlights

- **Native Windows app.** Chat, Model library, Hugging Face, Engine & devices, Benchmark Lab, System Doctor, Local API, Operations, Storage & cache and Settings are native WinUI screens backed by the same local engine as the browser interface. The browser interface remains available as an option.
- **Chat.** System prompt, temperature, top-p and maximum tokens per conversation, vision attachments for supported models, Markdown replies, live speed and context stats, and optional saved conversations (search, pin, archive, duplicate, Markdown/JSON export and JSON import).
- **Verified Model Library.** Import and export of model definitions without overwriting existing entries, adoption of compatible local models, per-model details (weight format, runtime, context window, vision, preferred device) and adaptive per-model context and memory management.
- **Benchmark Lab.** Multi-model, multi-device benchmark runs with Quick, Standard and Thorough presets, saved-run history, charts and compatible-run comparison.
- **Device routing.** Choose the engine default, a detected CPU, GPU or NPU, or a supported OpenVINO combination for each model; requested and actual devices are reported separately.
- **Native UI redesign.** Grouped navigation with live engine status, responsive card layouts, an inference settings pane with a context gauge, model cards with per-row actions, and Engine & devices / System Doctor dashboards with theme-aware, accessible charts.

## Fixes since 1.0.x

- Background status polls no longer rebuild, disable or close an open model or device dropdown; changes apply when the dropdown closes.
- System Doctor check titles, details and recommended actions, chart labels, gauge values, model card names and Benchmark Lab metrics are visible again (a code-built text helper had cleared the theme text color).
- Every dashboard card has a heading; charts and gauges show an empty-state or "Not reported" message instead of blank space.
- Status pills, model detail pills, model-health actions and benchmark labels wrap at narrow widths and high text scaling instead of clipping.

## Microsoft Store readiness

- Settings > About InferBridge shows the app version and links to the privacy policy, help and feedback, issue reporting, source code (MIT) and third-party notices.
- Microsoft Store installs never check for, link to or offer updates from outside the Store: update controls are hidden in the app and the tray's Check for Updates item is removed. The standalone installer keeps its opt-in, user-initiated update check.
- The Store package ships every logo at all display scales (100–400%), unplated taskbar icons, small and large tiles and a splash screen, indexed through `resources.pri`.
- The native app declares that it never requires administrator rights.
- First-run and empty states guide you to start the engine, download a first model and run a first benchmark. Help text and error messages use plain language instead of internal component names.

## Compatibility and security

- Data schema remains 1; no persistence migration is included. Existing settings, models and caches remain compatible.
- The MSIX package version is 1.1.0.0, greater than any earlier 1.0.x package.
- The Store package requests only `runFullTrust`. Microsoft re-signs it after certification. The standalone installer and portable ZIP remain unsigned unless a release states otherwise; verify them against the published SHA-256 checksums.
- Model downloads and Hugging Face search need an internet connection; chat and inference with downloaded models work offline.
- CI compiles the native client, runs contract tests and packs a structural MSIX; it does not verify physical CPU/GPU/NPU operation, installed upgrade behavior or Microsoft Store certification. See `docs/MICROSOFT_STORE.md` for the installed smoke test and WACK procedure.
