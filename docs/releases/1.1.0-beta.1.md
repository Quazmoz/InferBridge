# InferBridge 1.1.0-beta.1 — native Windows client beta

Minor feature release candidate following the 1.0.0 stable source baseline and the 1.0.1-dev.1 nightly. The native WinUI client is now the primary Windows experience. This is a pre-release source version: it is not a published, signed, or hardware-qualified release.

## Highlights

- **Native/web parity.** Chat (system prompt, vision attachments, Markdown, top-p, saved conversations with pin, archive and duplicate), Hugging Face discovery and conversion options, runtime upgrade and model health maintenance, Local API hub, restart, network listener, update checks and support diagnostics now have native WinUI screens backed by the same engine endpoints as the web UI.
- **Verified Model Library.** Native import/export of the model library without overwriting existing entries, adoption of compatible local models, per-model details (weight format, backend, context window, vision, preferred device) and adaptive per-model context and memory management.
- **Benchmark Lab.** Native multi-model benchmark runs with canonical presets, guarded progress, run correlation, saved-run comparison and fail-closed handling of synthetic or tampered rows; the web Benchmark Lab correlates runs with the same rules.
- **Device routing.** Explicit detected-device selector (engine default, physical device or supported OpenVINO combination) in native chat and the web UI, with requested and actual devices reported separately.
- **Dropdown fix.** Background status polls no longer rebuild, disable or close an open model/device dropdown; deferred updates apply when the dropdown closes.
- **Native UI redesign.** Grouped NavigationView rail with live engine status pills, responsive card grids, an inference pane with live stats and a context gauge, model library cards with per-row actions, Benchmark Lab charts, and Engine & devices / System Doctor dashboards built from in-house, theme-aware, accessible chart primitives (see `docs/NATIVE_UI_DESIGN.md`).

## Fixes in this beta

- System Doctor check cards showed only their Passed/Info pill: the shared text helper assigned a null foreground to every non-secondary code-built text block, which erased the theme text brush. Check titles, details and recommended next steps are visible again, and the same fix restores chart labels and values, gauge percentages and titles, model card names and Benchmark Lab metric values.
- Every dashboard card now has a heading; the Benchmark trend chart shows its title; charts and gauges show their empty-state or "Not reported" text instead of blank space.
- Status pills (rail footer, chat stats, model and benchmark rows) wrap to two lines, then trim with an ellipsis and a tooltip, instead of being clipped at the edge of the navigation pane.
- Model detail pills, model-health actions and the Benchmark activity label wrap at narrow widths and high text scaling instead of clipping.
- Code-built buttons keep their themed default style instead of receiving a null style.

## Compatibility and security

- Data schema remains 1; no persistence migration is included.
- The MSIX identity version derives from this version as 1.1.0.0, greater than 1.0.0.0.
- A stable build from `main` requires a stable (non-prerelease) version; the release preflight rejects `1.1.0-beta.1` on the stable channel by design.
- CI compiles the native client and runs contract tests but does not verify physical CPU/GPU/NPU operation, installed upgrade behavior, signing, or Microsoft Store certification.
