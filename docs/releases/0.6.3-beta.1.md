# OpenVINO Windows LLM 0.6.3-beta.1

## Highlights

- Beta release build for OpenVINO Windows LLM 0.6.3 package testing.
- Adds a consistent OpenVINO Windows LLM application icon to the browser client, packaged launcher, installer, Windows shortcuts, and uninstall registration.
- Generates deterministic multi-resolution PNG and ICO assets during the release build instead of relying on an untracked workstation file.
- Keeps unsigned builds available for local validation and non-stable channels without allowing them to be published accidentally as a stable release.
- Prevents chat and streaming requests queued during a device switch from resuming against an engine that has already been replaced and closed.
- Rejects normal unload requests while a model is serving or waiting on work, while preserving bounded forced cleanup during desktop shutdown.
- Replaces the previous immutable PyInstaller payload during an installer upgrade while preserving models, settings, logs, caches, onboarding state, and benchmark data under the separate user-data directory.
- Bundles psutil's Python and Windows-native components from one pinned release environment and rejects builds containing a missing, duplicate, or misplaced `_psutil_windows` extension.
- Replaces the raw PyInstaller traceback for incompatible packaged runtime files with privacy-safe repair guidance and a local sanitized startup diagnostic.
- Registers the installed primary tray with Windows Restart Manager so an upgrade can close and restart the application without registering helper processes or portable copies.

## Release validation required

This beta pre-release artifact package is built for non-production evaluation and channel testing.
