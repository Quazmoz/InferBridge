# OpenVINO Windows LLM 0.6.3-beta.1

## Highlights

- Beta release build for OpenVINO Windows LLM 0.6.3 package testing.
- Adds clear loaded, converted, preparing, unavailable, cancelled, and error states to the model selector using both text and color cues.
- Warns before loading or converting another model while one is already resident, with explicit choices to unload existing models or continue on high-memory hardware.
- Improves browser-window resizing across medium, compact, narrow, very narrow, short, and very short viewports without forcing a minimum 320-pixel content height.
- Preserves accessible sidebar state while moving between desktop and compact layouts and adds a dismissible overlay behind compact panels.
- Adds a consistent OpenVINO Windows LLM application icon to the browser client, packaged launcher, installer, Windows shortcuts, and uninstall registration.
- Generates deterministic multi-resolution PNG and ICO assets during the release build instead of relying on an untracked workstation file.
- Keeps unsigned builds available for local validation and non-stable channels without allowing them to be published accidentally as a stable release.
- Prevents chat and streaming requests queued during a device switch from resuming against an engine that has already been replaced and closed.
- Rejects normal unload requests while a model is serving or waiting on work, while preserving bounded forced cleanup during desktop shutdown.
- Replaces the previous immutable PyInstaller payload during an installer upgrade while preserving models, settings, logs, caches, onboarding state, and benchmark data under the separate user-data directory.
- Bundles psutil's Python and Windows-native components from one pinned release environment and rejects builds containing a missing, duplicate, misplaced, or sibling `_psutil_windows` extension.
- Replaces the raw PyInstaller traceback for incompatible packaged runtime files with repair guidance and a sanitized local startup diagnostic that redacts user paths, including paths containing spaces.
- Registers the installed primary tray with Windows Restart Manager so an upgrade can close and restart the application without registering helper processes or portable copies.
- Expands Windows CI coverage for installer upgrades, packaged runtime validation, model lifecycle UX, responsive UI behavior, PowerShell syntax, and packaging-script compilation.

## Release validation required

This beta pre-release artifact package is built for non-production evaluation and channel testing. A real Windows 11 install-over-existing-version test, packaged mock smoke test, and Intel CPU, GPU, and NPU validation remain required before promotion.
