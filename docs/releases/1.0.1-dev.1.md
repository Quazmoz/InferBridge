# InferBridge 1.0.1-dev.1 — nightly evaluation

Development-channel evaluation build following the 1.0.0 stable source baseline. This is not a stable release or a production certification.

## Highlights

- Preserve the recent `dev` improvements to the native Windows client, release packaging, and CI contracts.
- Align the canonical development version with the nightly channel required by the Azure Windows evaluation pipeline.
- Reject incompatible release channel/version combinations before expensive packaging begins, with regression coverage for stable, beta, and nightly builds.

## Compatibility and security

- Data schema remains 1; no persistence migration is included in this version update.
- Azure evaluation artifacts are unsigned and must not be represented as qualified or signed releases.
- A packaged mock smoke test does not verify physical CPU/GPU/NPU operation, installed upgrade behavior, signing, or Microsoft Store certification.
