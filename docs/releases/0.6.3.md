# OpenVINO Windows LLM 0.6.3

## Highlights

- Adds a consistent OpenVINO Windows LLM application icon to the browser client, packaged launcher, installer, Windows shortcuts, and uninstall registration.
- Generates deterministic multi-resolution PNG and ICO assets during the release build instead of relying on an untracked workstation file.
- Blocks stable GitHub publication unless both the installer and the launcher inside the portable ZIP carry verified Authenticode signatures.
- Keeps unsigned builds available for local validation and non-stable channels without allowing them to be published accidentally as a stable release.

## Release validation required

The release is not considered signed merely because `-Sign` was requested. Before publication, the build and publisher must both verify the installer and portable launcher with `signtool verify /pa /all`. A clean Windows 11 x64 installation, upgrade, uninstall, mock-mode startup, browser UI, icon rendering, and real Intel hardware paths remain to be validated by the release operator.
