# InferBridge 0.8.0

## Highlights

### Structured progress protocol
- Adds server-owned progress operations with a JSON Lines protocol for real-time model conversion and loading progress.
- Reconciles progress operations in the WebGUI so the browser always reflects the server's authoritative state, including across server restarts.
- Emits structured converter progress from the OpenVINO model converter pipeline.

### Model cancellation
- Adds operation-scoped model cancellation that safely aborts in-flight conversion or loading without corrupting server state.
- Installs guarded cancellation controls in the WebGUI with idempotent rendering.
- Preserves completed model operations during cancellation races.

### Model preparation recovery
- Persists sanitized recovery state after interrupted, cancelled, or failed conversion and loading operations.
- Distinguishes reusable Hugging Face source cache data from incomplete or complete OpenVINO conversion output.
- Adds a dedicated WebGUI recovery screen with resume, failed-stage retry, fresh-download restart, incomplete-output cleanup, and sanitized failure details.
- Keeps recovery actions operation-scoped with stale recovery-ID rejection and existing API-key and browser-origin protections.
- Prevents recovery cleanup from deleting complete models, symbolic links, paths outside the configured model directory, or the model-directory root.

See [Model preparation recovery](../MODEL_RECOVERY.md) for the recovery contract and API.

### Split status polling
- Adds split lifecycle telemetry and event APIs that separate model status, system telemetry, and event streams into independent polling channels.
- Composes split status polling in the WebGUI for reduced bandwidth and faster UI updates.
- Adds an expandable active operation queue in the WebGUI.

### Hugging Face access management
- Adds secure Hugging Face access management with DPAPI-protected token storage.
- Preflights unknown custom Hugging Face models before attempting conversion.
- Preserves gated-model recovery context in the UI with secret redaction.
- Installs Hugging Face manager safety guards for atomic writes and error handling.

### Stability and correctness
- Stabilizes long-running model loads with FIFO load waits and conservative caching.
- Keeps model load caching conservative to prevent stale state.
- Preserves FIFO model load wait ordering under concurrent requests.
- Fixes rate-limit window boundary expiry precision.
- Validates indexed OpenVINO devices precisely.
- Validates persisted model catalog entries on startup.
- Isolates desktop launch environment flags and control tokens.

### Testing
- Adds Playwright browser test infrastructure with Chromium-based server fixtures.
- Covers progress, cancellation, recovery, and status split behavior with Python and browser-facing contract tests.
- Expands Hugging Face access UI and manager safety regression coverage.
- Adds explicit JavaScript syntax, Windows compile, route security, stale-identity, cache-preservation, and bounded-cleanup checks for model recovery.

## Release validation required

Mock and static validation do not prove Authenticode signing, installer upgrade behavior, real Intel CPU, GPU, or NPU execution, or recovery behavior with every Hugging Face cache and checkpoint layout. Those checks require the documented Windows release and hardware certification procedures.
