# InferBridge 0.9.6-beta.3

This beta refresh incorporates the stable support and diagnostics improvements that landed on `main` after the beta line diverged, while preserving the newer beta architecture, installer hardening, security boundaries, and lifecycle work.

This is a **beta pre-release**. Release artifacts may be unsigned; if they are unsigned, Windows may report an unknown publisher and SmartScreen may warn. Verify downloads against the published SHA-256 checksums.

## Support and diagnostics

- Adds a low-friction **Send Feedback** entry point in System Doctor that opens the InferBridge support page without uploading diagnostics automatically.
- Adds tray **Copy → Diagnostics** for a concise, privacy-safe support summary derived only from allowlisted application, hardware, runtime, and configuration fields.
- Adds tray **Help → Send Feedback** and **Help → GitHub Issues** while keeping GitHub available for advanced technical discussion.
- Keeps ZIP diagnostics local and preserves explicit confirmation before export.
- Keeps credentials, prompts, chat history, browser storage, logs, model files, and private model paths out of the copyable support summary.

## Beta integration hardening

- Integrates the support UI through the beta branch's declarative `UiExtension` registry instead of restoring the older import-order injection chain from stable.
- Preserves junction/reparse-point rejection for diagnostics output roots on Windows.
- Preserves collision-safe diagnostic ZIP naming for concurrent tray/server export paths.
- Retains the 0.9.6-beta.2 installer and first-launch bootstrap protections, including installed-runtime bootstrap validation and semantic-version downgrade guards.
- Retains the newer desktop API-key, browser-authentication, LAN exposure, local-request, model lifecycle, storage, and recovery hardening already present on the beta line.
- Retains expanded Windows CI coverage for release, packaging, installer, security-boundary, UI, lifecycle, and resilience contracts.

## Compatibility

- Persistent data schema remains version 1.
- Existing 0.9.5 and 0.9.6 beta models, settings, caches, browser history, onboarding state, and diagnostics remain compatible.
- Installer identity and install location remain unchanged for in-place upgrades.

## Qualification

Source and mock-mode validation do not prove physical-device behavior. Before promoting this beta to stable, validate a fresh install and an in-place upgrade on real Windows hardware, then confirm tray startup, server readiness, browser opening, model preparation, CPU/GPU/NPU behavior on the available hardware, uninstall, and retained user data. Authenticode claims are valid only when the release signing gate completes successfully.
